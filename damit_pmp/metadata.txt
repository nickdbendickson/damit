description=NOAA Atlas 14 precipitation-frequency estimates for dam safety work (Processing provider damit_pmp): point and basin tables from the NOAA/NWS Precipitation Frequency Data Server, Atlas 14 GIS grids fetched from NOAA for any return period and duration, a design hyetograph (alternating block, NOAA Atlas 14 temporal distributions or NRCS 24-hour types, with optional initial / constant losses), the watershed of a dam point from a DEM, basin statistics, and LISFLOOD-FP / ANUGA rain-on-grid files and jobs. NOAA Atlas 14 is the only data source.
about=damit_pmp:pointpf and damit_pmp:basinpf query PFDS (https://hdsc.nws.noaa.gov/pfds/) for the 19 Atlas 14 durations (5 min - 60 days) and the PDS 1 - 1000-year ARIs or AMS 1/2 - 1/1000 AEPs with 90% bounds, cache the answers, and write a CSV table and a JSON file recording the Atlas 14 volume, version, region, query URL, fetch time and citation. damit_pmp:fetchgrid downloads the Atlas 14 'PF in GIS format' grid (hdsc.nws.noaa.gov/pub/hdsc/data) for the return period, duration, series (PDS / AMS) and bound (estimate, 90% lower, 90% upper) you choose, clips it to a point buffer, extent or basin, and writes a GeoTIFF in inches with a JSON sidecar (URL, fetch time, SHA-256, citation). damit_pmp:hyetograph builds a design hyetograph from the point table (the Atlas 14 depth always; the shape is the alternating block, a NOAA Atlas 14 Volume 8 temporal distribution or an NRCS Type I / IA / II / III curve; optional initial and constant losses give excess rain); damit_pmp:watershed delineates the watershed of a dam point from a DEM (a file, or USGS 3DEP fetched for you) and compares it with the NID drainage area; damit_pmp:gridbasin gives the basin mean / min / max of an Atlas 14 grid (a file you have or one it fetches); damit_pmp:raingrid writes the storm as a LISFLOOD-FP .rain file (mm/hr) and an ANUGA rate series (m/s); damit_pmp:anugarain sets up an ANUGA rain-on-grid job on the damit_runner gmsh mesh (the runner's own mesher, sizes and domain build, a ready-to-run script and a run manifest). damit_pmp:lisfloodrain sets up the same storm on the same domain as a LISFLOOD-FP job with damit_runner's setup (solver ACC by default). It launches no model: the gmsh mesh is built only when you give an ANUGA Python, ANUGA runs only if you switch RUN_ANUGA on and LISFLOOD-FP only if you switch RUN_LISFLOOD on (both off by default). A location outside Atlas 14 coverage fails with a clear message. Atlas 14 publishes frequency estimates up to the 1000-year ARI: this plugin computes no probable maximum precipitation and uses no PMP study, HMR, state PMP tool or other precipitation source (it is not a port of the DamSafety PMP / North Dakota PMP Evaluation Tool and ships none of its data).
