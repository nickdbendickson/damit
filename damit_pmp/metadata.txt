description=NOAA Atlas 14 precipitation-frequency estimates for dam safety work (Processing provider damit_pmp): point and basin tables from the NOAA/NWS Precipitation Frequency Data Server, Atlas 14 GIS grids fetched from NOAA for any return period and duration, an alternating-block design hyetograph, basin statistics, and LISFLOOD-FP / ANUGA rain-on-grid files. NOAA Atlas 14 is the only data source.
about=damit_pmp:pointpf and damit_pmp:basinpf query PFDS (https://hdsc.nws.noaa.gov/pfds/) for the 19 Atlas 14 durations (5 min - 60 days) and the PDS 1 - 1000-year ARIs or AMS 1/2 - 1/1000 AEPs with 90% bounds, cache the answers, and write a CSV table and a JSON file recording the Atlas 14 volume, version, region, query URL, fetch time and citation. damit_pmp:fetchgrid downloads the Atlas 14 'PF in GIS format' grid (hdsc.nws.noaa.gov/pub/hdsc/data) for the return period, duration, series (PDS / AMS) and bound (estimate, 90% lower, 90% upper) you choose, clips it to a point buffer, extent or basin, and writes a GeoTIFF in inches with a JSON sidecar (URL, fetch time, SHA-256, citation). damit_pmp:hyetograph builds an alternating-block hyetograph from the point table; damit_pmp:gridbasin gives the basin mean / min / max of an Atlas 14 grid (a file you have or one it fetches); damit_pmp:raingrid writes the storm as a LISFLOOD-FP .rain file (mm/hr) and an ANUGA rate series (m/s). It launches no model. A location outside Atlas 14 coverage fails with a clear message. Atlas 14 publishes frequency estimates up to the 1000-year ARI: this plugin computes no probable maximum precipitation and uses no PMP study, HMR, state PMP tool or other precipitation source (it is not a port of the DamSafety PMP / North Dakota PMP Evaluation Tool and ships none of its data).
