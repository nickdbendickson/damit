description=Keeps offline copies of public structure and building-footprint layers for any US state (or an extent): USACE NSI, Microsoft US Building Footprints, OpenStreetMap (Geofabrik) and, with a pasted link, FEMA / ORNL USA Structures. Processing provider damit_data.
about=damit_data:download fetches the chosen sources for the chosen state (NSI county by county, or one request for a small extent), stages and verifies each download (zip integrity, GeoJSON), and replaces the local copy only when the source changed (ETag / Last-Modified / size, or the NSI content hash). Files go to <data folder>/<state or extent>/<source>/ with a manifest (versions, citations); the data folder is the tool's folder, else the DamIT data_folder setting (DamIT Setup), else ~/Documents/DamIT Data. A folder inside an ND Dam Suite offline pack is refused. damit_data:status lists what is held; the menu adds the layers to the project. Generalized from the North Dakota-only DamSafety Data; the ND-specific layers (ND 911 address points, NDDOT, DWR, ND offline pack) are not part of DamIT Data 0.1.0.
