description=Dam breach model runs (Processing provider damit_run): damit_run:rundam accepts a DamIT Screener hand-off package (or equivalent parameters), validates it against DamIT Catalog (NID dams only: the dam needs its NID ID unless new / proposed or a desk sample), prepares the run and launches the breach model with the DamSafety Runner's parameters and defaults (breach hydrograph, LISFLOOD-FP executable or the built-in engine when none is installed, optional ANUGA tier on the DamSafety mesh, growth loop and grid refinement), writing Depth (Max), Velocity (Max), Arrival Time, WSE (Max), hmax and the flood polygons into the dam folder for DamIT Hazard.
about=Generalized from the DamSafety Runner breach-run workflow for the DamIT presets. Tools: damit_run:rundam (DRY_RUN on = prepare / record only; HEC-RAS is refused) and damit_run:checkhandoff. It never starts HEC-RAS, Wine, ndbreach:rundam or ndbreach:batch, and always creates a new run folder rather than writing into an existing one. Also ships the flood package (breach hydrographs, built-in LISFLOOD-FP and finite-volume engines) used by DamIT Screener. Classification of finished rasters is DamIT Hazard's job (damit:classify); the Runner attaches catalog metadata only. Suggested classifications only; the engineer of record and the regulating agency make the determination.
