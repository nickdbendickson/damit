about=Full breach engine ported from DamSafety Runner (~59K lines). LISFLOOD-FP (built-in local inertial solver), ANUGA 2D mesh refinement, HEC-RAS 2D (Windows/Wine). Workflow: breach hydrograph -> terrain/DEM prep -> adaptive domain -> model run -> flood scenario -> post-processing -> report. Processing tools: damit_run:rundam, damit_run:batch, damit_run:sensitivity, damit_run:cascade, damit_run:hydrograph, damit_run:estimate, damit_run:check, damit_run:finishanuga. Classification is DamIT Hazard's job (damit:classify). Suggested classifications only; the engineer of record and the regulating agency make the determination.
