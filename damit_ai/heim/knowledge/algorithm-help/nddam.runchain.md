15 - Run the steps in order (headless) (nddam:runchain)

----------------
Description
----------------
The window's 'Run the steps in order' as a tool, so a statewide run can go through qgis_process or a script overnight. Steps 1, 2, 3, 4, 5, 7, 8 and 10 that are not done (or are out of date: an input changed since they ran) run one after the other in the work folder with the values the window would fill in (the work folder's files, the data package, the settings JSON the window exports). Optional steps 0, 6 and 9 run if ticked; 7b and 11-14 never. It stops at the first step that fails, lacks an input or writes no output, and says which. Settings JSON keys: see core/workflow.DEFAULT_SETTINGS (layers as file paths; the data package fills the rest).

qgis_process run nddam:runchain --WORK=/path/to/work --SETTINGS=/path/to/damsuite_settings.xlsx --INCLUDE=1

The preflight check (17) runs first and a FAIL stops the chain before anything starts (PREFLIGHT=false skips it). A copy of the settings used goes to <work>/settings_used.xlsx. Not run in a real QGIS.

A chain that fails, is refused by the preflight or cannot start FAILS the tool, so qgis_process exits non-zero; FAIL_ON_ERROR=false returns OK=false instead.
