```
Compare with a reference model (e.g. HEC-RAS) (ndbreach:benchmark)

----------------
Description
----------------
Compares a dam's breach rasters with another model's on the same grid: fit index (extent agreement), hit and false-alarm rates, depth bias / RMSE / 90th-percentile error, depth-class agreement, and velocity and arrival-time differences. Writes a difference raster, an extent agreement raster (1 = only this tool, 2 = only the reference, 3 = both), a CSV and an HTML report. Reference rasters are read onto this tool's grid.

----------------
Arguments
----------------

DAM_FOLDER: Dam folder with 'Depth (Max).tif' etc.
	Argument type:	file
	Acceptable values:
		- Path to a file
REF_DEPTH: Reference max depth raster
	Argument type:	raster
	Acceptable values:
		- Path to a raster layer
REF_VELOCITY: Reference max velocity raster (optional)
	Argument type:	raster
	Acceptable values:
		- Path to a raster layer
REF_ARRIVAL: Reference arrival time raster (optional)
	Argument type:	raster
	Acceptable values:
		- Path to a raster layer
REF_WSE: Reference max water surface elevation raster (optional)
	Argument type:	raster
	Acceptable values:
		- Path to a raster layer
REF_UNITS: Reference units
	Default value:	0
	Argument type:	enum
	Available values:
		- 0: US customary (ft, ft/s, hours)
		- 1: Metric (m, m/s, hours)
	Acceptable values:
		- Number of selected option, e.g. '1'
		- Comma separated list of options, e.g. '1,3'
THRESH_FT: Wet where the depth is at least (ft; starting value 1 is the engineer's, a screening value you choose)
	Default value:	1
	Argument type:	number
	Acceptable values:
		- A numeric value
		- field:FIELD_NAME to use a data defined value taken from the FIELD_NAME field
		- expression:SOME EXPRESSION to use a data defined value calculated using a custom QGIS expression
OUT_FOLDER: Output folder (empty = <dam folder>/_benchmark) (optional)
	Argument type:	file
	Acceptable values:
		- Path to a file

----------------
Outputs
----------------

SUMMARY: <outputFile>
	Benchmark_Summary.csv
REPORT: <outputFile>
	Benchmark report (HTML)
VERDICT: <outputString>
	Verdict
```
