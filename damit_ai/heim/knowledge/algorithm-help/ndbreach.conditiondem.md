Preview the DEM conditioning around a dam (ndbreach:conditiondem)

----------------
Description
----------------
Writes the DEM as the models will see it after the channels are burned, ponds lowered and culverts, bridges and notches cut, around a dam, so it can be checked before a long run (compare it with the original). Also writes the ponds' initial water depth. The source DEM is never changed; the breach tools apply the same edits on the fly.
