Import DSS-WISE Lite results (ndhazard:dsswise)

----------------
Description
----------------
Converts a DSS-WISE Lite Simulation Results Package (zip or folder) to depth (ft), velocity (ft/s), depth x velocity (ft2/s) and arrival (h) GeoTIFFs and summarises the HCOM and discharge tables. Roles and units are recognised from the file names; check DSSWISE_Import_Summary.txt.

----------------

----------------

PACKAGE: Results package (zip) (optional)
	Argument type:	file

		- Path to a file
FOLDER: or: unzipped package folder (optional)
	Argument type:	file
	Acceptable values:
		- Path to a file
DEPTH_UNITS: Depth units
	Default value:	0
	Argument type:	enum
	Available values:
		- 0: from file names
		- 1: ft
		- 2: m
	Acceptable values:
		- Number of selected option, e.g. '1'
		- Comma separated list of options, e.g. '1,3'
VEL_UNITS: Velocity units
	Default value:	0
	Argument type:	enum
	Available values:
		- 0: from file names
		- 1: ft/s
		- 2: m/s

		- Number of selected option, e.g. '1'
		- Comma separated list of options, e.g. '1,3'
