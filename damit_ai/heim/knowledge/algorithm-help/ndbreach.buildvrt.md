Build a statewide LiDAR DEM mosaic (VRT) (ndbreach:buildvrt)

----------------
Description
----------------
Mosaics a folder of LiDAR DEM tiles into one virtual raster (VRT) without copying any data, so the breach tools can read any dam from the statewide set offline. Tiles in a different CRS than most are left out and listed; differing cell sizes or elevation units are reported. Use the VRT as the DEM of the other tools.

----------------
Arguments
----------------

TILES: Folder of DEM tiles (searched recursively)
	Argument type:	file
	Acceptable values:
		- Path to a file
NODATA: No-data value (empty = taken from the tiles) (optional)
	Argument type:	number
	Acceptable values:
		- A numeric value
		- field:FIELD_NAME to use a data defined value taken from the FIELD_NAME field
		- expression:SOME EXPRESSION to use a data defined value calculated using a custom QGIS expression
OUTPUT: DEM mosaic (VRT)
	Argument type:	fileDestination
	Acceptable values:
		- Path for new file

----------------

	DEM mosaic (VRT)
VRT: <outputFile>

	Result
