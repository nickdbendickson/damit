Inflow hydrograph from PMP hyetographs (ndpmp:inflow_hydrograph)

----------------
Description
----------------
Reads nd_pmp hyetograph CSVs and computes inflow hydrographs (SCS CN or initial+constant losses; SCS or Clark UH; constant or recession baseflow). Output: hydrographs/<storm_id>.csv (time_hr, flow_cfs, precip_in, excess_in) + inflow_hydrograph_summary.csv. INTERNAL PROTOTYPE.<br><br>Basin inputs: Plugins ▸ DamSafety PMP ▸ Get basin data from StreamStats… fills the drainage area, a suggested non-contributing area and Tc / lag from USGS StreamStats, and sets 'StreamStats basin values'. With that file set, the largest peak is compared with the ND 0.2% AEP regression peak and the Crippen & Bue envelope after the run (a warning in the log, never a block; streamstats_pmf_check.json). The curve number is never taken from StreamStats.
