Batch hazard classification (folder of dams) (ndhazard:batch)

----------------
Description
----------------
Runs the hazard classification for every dam folder directly inside the chosen folder. Each dam folder's rasters are found by name (RAS Mapper 'Depth (Max)', 'Velocity (Max)', 'Arrival Time', 'D * V (Max)', time-step folders, no-breach rasters; DSS-WISE names). Results go to each dam's outputs folder; Batch_Hazard_Classification.csv lists the class of every dam. A dam that fails or has no depth raster is listed and skipped. WORKERS > 1 classifies that many dams at the same time, each in its own qgis_process child process (needs qgis_process and the plugin enabled in that QGIS profile - set ND_QGIS_PROCESS to its full path if it is not found; falls back to one dam after another when it is missing, and says so in MODE). TIMEOUT_MIN ends a worker that takes longer (that dam is listed as failed). WORKERS = 1 (default) runs the dams one after another in this session; each dam's downloaded data stays in this session's memory until QGIS closes, so use WORKERS > 1 for a long batch (each dam's memory is released when its process ends). BOUNDARY: the model edge check can use each dam folder's HEC-RAS 2D flow area polygon (model_boundary_2d_area.gpkg, written by 'Import HEC-RAS plan results'); a dam without the file gets the automatic check.
