Culvert prep: corrected copy of the structures layer (review list) (ndbreach:culvertprep)

----------------
Description
----------------
Before a run: checks each culvert end of a structures layer against the run's fine DEM with the run's own rules (the culvert pre-check) and writes a corrected COPY - the input layer is never changed.
An end whose given invert is more than 0.3 m above the lowest fine ground within max(apron, 5 m) gets that lowest ground as its invert (LiDAR-derived, not surveyed), with a note on the feature. A change is applied only when it is within the limit (1 ft to start; the engineer's choice) and the end is on native fine ground (the composite DEM's top source, 1 m cells or finer). Larger changes, ends on a fill source or a coarser DEM, ends with no fine ground (the run uses the model DEM there) and line straightening are FLAGGED: left unchanged in the copy and listed in the change log for review.
The change log (culvert_prep_<dam>.md / .csv / .json, beside the copy) records the sha256 of the input and of the copy and every item. To apply flagged items, put yes in the accept column of the CSV (or list item ids in a text file) and run again from the SAME input with it as the accept list.
No structures layer? Leave it empty and give the inventories: ND Dam Hazard's 'Culvert and bridge lines for DamSafety Runner' builds it first (layers left empty come from its offline data pack).
The run is unchanged: point the run's structures layer at the copy to use it. The bed floor and the channel-bed check still apply in the run.
