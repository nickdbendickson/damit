5 - Breach parameters and hydrograph (nddam:breachhydrograph)

----------------
Description
----------------
ND Dam Safety Standards 5.1.1 scenario: water at the top of dam, no added inflow, no downstream flooding, piping breach (td_ fields). Optional sunny-day run at normal pool (sd_ fields). Breach width and formation time: Froehlich (2008) by default; Froehlich (1995), Von Thun & Gillette (1990, easily erodible or erosion resistant) and MacDonald & Langridge-Monopolis (1984; the embankment section is assumed 12 ft crest, 3H:1V faces because the inventory has neither) can be chosen, with the same formulas as the ND Dam Breach Runner, and tool 9 runs them as a sensitivity. NRCS TR-60 gives a peak discharge instead (its lower / upper limits applied, the same assumed section) with a triangular or curvilinear hydrograph whose volume is the releasable storage and whose rise time is the Froehlich (2008) formation time; it is not routed.
YOUR OWN BREACH PARAMETERS: 'Where the breach parameters come from' lets fields of the dams layer (average width ft, formation time hr, side slope H:1V, breach bottom elevation ft in the DEM datum) or one set of typed values replace the equation. A field wins where it is filled (> 0; the bottom elevation where not empty), then a typed value (> 0), then the equation; brch_src records which source gave each dam's width / time / slope / bottom. A breach bottom above the toe leaves the storage below it behind the dam.
The hydrograph is level-pool routed through a growing trapezoidal breach over the stage-storage curve from tool 3 (calibrated to inventory normal storage by tool 3 when available). Froehlich (1995) and NRCS TR-60 peaks are given as cross-checks (TR-60 only above 10.5 ft of water). Simplification: piping is modelled as a top-down weir breach with no orifice phase and no tailwater. simplified = YES marks dams under 200 ac-ft, which the ND policy may allow to skip breach modelling when the classification is obvious. Screening-level only.
