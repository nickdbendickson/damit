Export the breach to HEC-RAS (2D model package, hydrograph and breach table) (ndbreach:hecrasexport)

----------------
Description
----------------
v3.10.16: builds a complete HEC-RAS 6.x 2D dam-breach model of a finished run (reservoir storage area, the dam as an SA/2D connection with the breach, the flooded valley as a 2D area, normal-depth outflow, the run's culverts and bridges) in '<dam folder>/_breach_model/hecras/<DamID>_<date>/' with a .zip of it to copy to a Windows PC with HEC-RAS 6.6, and WINDOWS_README.txt with the steps left to do in HEC-RAS (terrain, mesh, run) and what to send back. The model has NOT been opened in HEC-RAS by the plugin; with an output folder chosen, the package goes in '<folder>/hecras'. Also reads a finished run's breach hydrograph and parameters from its dam folder and writes (1) the hydrograph as an unsteady-flow text block for a HEC-RAS '.u##' file ('Flow Hydrograph= N', 10 values a line, 8-character fields) and as a CSV, on the time step you choose (the peak is kept exactly), and (2) the values HEC-RAS's breach editor asks for (final bottom elevation and width, side slopes, weir coefficient, formation time, trigger) as CSV and markdown. The values marked 'Plugin estimate' come from regression equations and are not design values; the breach center station is left blank. Use the same data interval in the HEC-RAS boundary condition as the step chosen here. Output goes to '<dam folder>/_hecras' unless you choose a folder.
