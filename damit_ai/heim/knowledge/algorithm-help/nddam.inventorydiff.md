13 - Inventory diff (what changed since the last run) (nddam:inventorydiff)

----------------
Description
----------------
Compares two dam inventories by dam ID: two tool-1 layers, or a new DWR 'Dams by Hazard Class' export against the last one (tool 1's default field names: structure_, dam_name, max_dam_he, normal_vol, max_pool_v, hazard_cla, status; a layer with a dam_id field is taken as a tool-1 layer). Reports new dams, removed dams, and dams whose height, normal / max storage, status, existing class, name or location changed.
Thresholds are screening values you choose: height from 0.5 ft, storage from 2 % (and at least 1 ac-ft), location moved more than 50 m (164 ft).
Output: inventory_changes.csv (one row per new / removed dam and per changed field, values in ft / ac-ft next to the metric ones) and a point layer of the changed dams (the new location; the old one for removed dams). With a Dams folder, every changed dam that has <Dams>/<dam ID>/dam.json gets an 'inventory_change' entry ({when, fields, note}) so the suite's 'next action' can say 'refresh'; nothing else in the record is touched and no folder is created. Not run in a real QGIS during development (test doubles only).
