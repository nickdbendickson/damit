Fill no-data gaps in a DEM (ndbreach:fillgaps)

----------------
Description
----------------
Fills no-data holes (water bodies, missing returns, tile seams) by interpolating from their edges, over the whole raster or an extent. LISFLOOD-FP treats no-data as very high ground, so a hole in the flood path dams the flood. The whole area is read into memory, so give an extent around the dam and its flood path for a statewide mosaic. Fills only holes up to the search distance; the rest are counted and reported.

----------------
Arguments
----------------

DEM: DEM
	Argument type:	raster
	Acceptable values:
		- Path to a raster layer
EXTENT: Area to fill (empty = all) (optional)
	Argument type:	extent
	Acceptable values:
		- A comma delimited string of x min, x max, y min, y max. E.g. '4,10,101,105'
		- Path to a layer. The extent of the layer is used.
MAX_DIST: Fill holes up to this many cells across
	Default value:	100
	Argument type:	number
	Acceptable values:
		- A numeric value
		- field:FIELD_NAME to use a data defined value taken from the FIELD_NAME field
		- expression:SOME EXPRESSION to use a data defined value calculated using a custom QGIS expression
SMOOTH: Smoothing passes over the filled cells
	Default value:	0
	Argument type:	number
	Acceptable values:
		- A numeric value
		- field:FIELD_NAME to use a data defined value taken from the FIELD_NAME field
		- expression:SOME EXPRESSION to use a data defined value calculated using a custom QGIS expression
OUTPUT: Filled DEM
	Argument type:	fileDestination
	Acceptable values:
		- Path for new file

----------------
Outputs
----------------

OUTPUT: <outputFile>
	Filled DEM
FILLED: <outputFile>
	Filled DEM
RESULT: <outputString>
	Result
