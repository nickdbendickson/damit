Breach hydrograph only (ndbreach:hydrograph)

----------------
Description
----------------
Computes the ND 5.1.1 breach hydrograph without running a flood model, for checking the breach parameters. Writes the hydrograph CSV and a plot and prints the parameters, the routed peak, the Froehlich (1995) peak and, when the embankment geometry is given, the TR-60 peak.
