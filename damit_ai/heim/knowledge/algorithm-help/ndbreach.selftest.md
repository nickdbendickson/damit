Self-test the installation in this QGIS (ndbreach:selftest)

----------------
Description
----------------
Checks that this QGIS can run the plugin: GDAL and the QGIS, Python and numpy versions; that every tool of the plugin is registered; LISFLOOD-FP (and a tiny flood run) and the ANUGA environment; and, on a small synthetic valley, the GeoTIFF writing and reading, unit handling, reprojection, DEM mosaics, gap filling and land-cover roughness. With 'Run a small model as well' it runs a whole dam breach on that valley (seconds with LISFLOOD-FP). Each check is PASS, FAIL (with the exact error) or SKIP (with the reason).

The report is written to a text file and printed in the log, ending with a block to copy and send to the developer if anything failed.
