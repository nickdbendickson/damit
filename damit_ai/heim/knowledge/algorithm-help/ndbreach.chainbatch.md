Batch chain: Screening → Runner → HEC-RAS → Hazard, dam by dam (ndbreach:chainbatch)

----------------
Description
----------------
Takes a list of dams and runs each one through the suite before starting the next: the Screening steps for that dam, the Runner, the HEC-RAS 2D model build and run, the Hazard import of the HEC-RAS results and the ND + TM11 classification (whose window state is saved as <dam>/Hazard_<ID>.qgz). A dam that fails does not stop the list.

HEC-RAS 2D stage: 'Run' (the Runner's own HEC-RAS stage where HEC-RAS can run, else as 'Wait'), 'Wait for a manual HEC-RAS run' (the model is built and the chain waits for its <name>.p01.hdf; 0 minutes = the dam stops at 'waiting for HEC-RAS' and the next run of the chain continues it) or 'Skip' (the Runner's rasters go straight to the classification).

Settings: the suite settings file (each tool's rows), an overrides CSV (dam_id + only the values that differ, columns plugin.tool.KEY or a chain key), a preflight before anything starts. Writes Chain_Batch_Summary.csv and chain_manifest.json in the output folder and <dam>/_chain/chain_settings_used.json for each dam.
