Review habitable structures (engineer sign-off) (ndhazard:reviewhabitable)

----------------
Description
----------------
Saves an engineer's habitability decision for structures that are not ND 911 address points. Only ND 911 address points are habitable by themselves; every other structure stays 'unverified' (counted, not plotted on the depth-velocity chart) until it is reviewed here. The decision goes into habitable_review.json in the dam folder; classify and the chart only read it. This tool is the only writer, and only when you run it (a classify run never creates or changes the file). Give the structure keys (the struct_key column of ND_DV_Habitable_unverified.csv, typed or as the CSV), the decision and who decided. 'Remove' deletes the review. Every change is kept in the file's history. The existing Review tab (Structure_Review_Decisions.csv) still applies category / type / persons decisions as before.

----------------
Arguments
----------------

FOLDER: Dam folder (habitable_review.json is created or updated in it) or the path of the review file
	Argument type:	file
	Acceptable values:
		- Path to a file

	Argument type:	string

		- field:FIELD_NAME to use a data defined value taken from the FIELD_NAME field
		- expression:SOME EXPRESSION to use a data defined value calculated using a custom QGIS expression
KEYS_CSV: Or a CSV with a struct_key column (e.g. the unverified worklist, edited to the rows reviewed) (optional)
	Argument type:	file
	Acceptable values:
		- Path to a file

	Default value:	0
	Argument type:	enum
	Available values:
		- 0: Habitable (an engineer reviewed: people live or work there)
