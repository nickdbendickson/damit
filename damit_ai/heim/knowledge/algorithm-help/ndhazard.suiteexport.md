Export data package for ND Dam Breach Screening (ndhazard:suiteexport)

----------------
Description
----------------
Writes ONE GeoPackage (EPSG:5070) in the standard schema of ND Dam Breach Screening's '0 - Build offline data package', from ND Dam Hazard's offline data pack or a folder of its downloads: structures (habitable 1/0, mobile 1/0, occ_cls, prim_occ - ND Dam Hazard's own habitability and manufactured-home rules on each structure's attributes; 'Unverified' is written as habitable = 1), structure_points (the same as points, for DamSafety Runner's receptors), roads (aadt, road_class, level - AADT joined the way ND Dam Hazard's classification joins it; unknown AADT stays empty, never 0), railroads (passenger, trains_day, level), flowlines, lifelines (category) and dams (NID).
NHD waterbodies are included when the offline pack has them. Not exported: the DWR dam lines and any DEM - give those to the Screening tools yourself. The run log lists the counts and what is missing; the table 'suite_export_info' in the GeoPackage keeps it.
Area: North Dakota's box by default (features touching it are exported whole).

----------------
Arguments
----------------

PACK: ND Dam Hazard offline data pack (.zip / .sqlite; empty = the pack chosen on the Data tab, if any) (optional)
	Argument type:	file
	Acceptable values:
		- Path to a file
DOWNLOADS: or: a folder of ND Dam Hazard downloads (a dam output folder, its _downloads folder or a folder of dams) (optional)
	Argument type:	file
	Acceptable values:
		- Path to a file
EXTENT: Area (empty = North Dakota) (optional)
	Argument type:	extent
	Acceptable values:
		- A comma delimited string of x min, x max, y min, y max. E.g. '4,10,101,105'
		- Path to a layer. The extent of the layer is used.
STRUCTURES: Structures from
	Default value:	0
	Argument type:	enum
	Available values:
		- 0: Automatic: FEMA USA Structures, else NSI, else ND address points
		- 1: FEMA USA Structures outlines
		- 2: USACE National Structure Inventory points
		- 3: ND GIS Hub site address points
	Acceptable values:
		- Number of selected option, e.g. '1'
		- Comma separated list of options, e.g. '1,3'
OUTPUT: Data package (GeoPackage)
	Argument type:	fileDestination
	Acceptable values:
		- Path for new file

----------------
Outputs
----------------

OUTPUT: <outputFile>
	Data package (GeoPackage)
SUMMARY: <outputString>
	Summary
