Hazard class probability from an ensemble of breach runs (ndhazard:ensemble)

----------------
Description
----------------
Classifies every run of an ensemble (e.g. the ND Dam Breach Runner's <dam>/Probabilistic/Runs/run_NNN folders, or any folder of sub-folders with depth / velocity / arrival rasters) with this plugin's pipeline and the SAME settings and data as the dam's own last run (outputs/QA/Run_Settings.json; downloads are re-used, not fetched per run), and writes outputs/QA/Class_Probability.csv / .html: P(ND High / Medium / Low), P(TM 11 classes), weighted when every run.json has a weight, with the run IDs of each class, and per structure the probability of the probable loss of life zone. The probabilities are only as good as the ensemble's parameter distributions - the runner's defaults are placeholders. Each run's outputs: outputs/QA/Ensemble/<run>. A finished run is not classified again when its rasters and settings are unchanged.

----------------
Arguments
----------------

ENSEMBLE_FOLDER: Ensemble folder (run sub-folders; a dam folder or its Probabilistic folder also works)
	Argument type:	file
	Acceptable values:
		- Path to a file
DAM_FOLDER: Dam folder (its settings, data and outputs/QA are used)
	Argument type:	file
	Acceptable values:
		- Path to a file
CONFIG_JSON: Advanced: JSON file with pipeline settings (as ndhazard:classify) (optional)
	Argument type:	file
	Acceptable values:
		- Path to a file
MAX_RUNS: Largest number of runs to classify (the first ones in name order)
	Default value:	200
	Argument type:	number
	Acceptable values:
		- A numeric value
		- field:FIELD_NAME to use a data defined value taken from the FIELD_NAME field
		- expression:SOME EXPRESSION to use a data defined value calculated using a custom QGIS expression
