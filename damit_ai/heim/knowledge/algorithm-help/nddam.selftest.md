14 - Self-test in this QGIS (nddam:selftest)

----------------
Description
----------------
Builds a synthetic valley with one dam in a temporary folder (10 m DEM, 7 m embankment, pool, road, structures, railroad, stream, dam line, a DWR-style inventory row) and runs tools 1, 2 (local DEM folder), 3, 4, 5, 6, 7 (built-in engine, small grid), 8, 10 and 16 (ponds and dugouts, on the pool above the dam) one after the other through processing.run, checking that each wrote what the next one needs. PASS / FAIL per step with timings and the QGIS / GDAL / numpy versions go to the report. Run it first in a new QGIS or after a QGIS upgrade: a failure names the step and the error. It says nothing about model accuracy - nothing about the dam is real. Tools 0, 7b, 9 and 11-13 are not covered.

This plugin was developed without a real QGIS (simulated QGIS / Qt only), so this self-test is the first thing that has to pass.
