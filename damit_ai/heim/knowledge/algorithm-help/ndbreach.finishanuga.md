```
Finish an ANUGA run after QGIS closed (ndbreach:finishanuga)

----------------
Description
----------------
Since 3.12.2 ANUGA runs detached from QGIS: it writes its own log (_breach_model/anuga/anuga.log) and status (anuga_worker.json), and it goes on when QGIS closes or crashes, then writes anuga_result.npz. This tool runs 'Run breach model for one dam' again with the parameters that run saved (_breach_model/run_params.json) and Resume on: LISFLOOD-FP is reused, a worker still running is waited for, a finished result is used, and the rasters, products, run_report.json and the report are written as usual. It works the same from qgis_process:

qgis_process run ndbreach:finishanuga -- DAM_FOLDER=/path/to/Dams/DWR-2801

----------------
Arguments
----------------

DAM_FOLDER: Dam folder (the run's output folder, with _breach_model)
	Argument type:	file
	Acceptable values:
		- Path to a file
REQUIRE_WORKER: Only when an ANUGA run is waiting (stop otherwise)
	Default value:	false
	Argument type:	boolean
	Acceptable values:
		- 1 for true/yes
		- 0 for false/no
		- field:FIELD_NAME to use a data defined value taken from the FIELD_NAME field
		- expression:SOME EXPRESSION to use a data defined value calculated using a custom QGIS expression

----------------
Outputs
----------------

RESULT: <outputString>
	Result
```
