Flood polygons and EAP map from a dam's rasters (ndbreach:products)

----------------
Description
----------------
Makes the flood-depth polygons, arrival zones, GeoPackage and EAP inundation map from the rasters in a dam folder ('Depth (Max).tif', 'Arrival Time.tif'), for runs made earlier or by another model. The dam point marks the dam on the map; give it in the raster's CRS.

The EAP map is ND Dam Hazard's map book (a PDF on aerial imagery). This tool's map is a preview, 'EAP Inundation Map (preview).svg', drawn by default only when ND Dam Hazard is not installed (parameter 'EAP map').
