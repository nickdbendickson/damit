ACER TM 11 chart sign-off (chart file for the Breach Runner / Screening) (ndhazard:chartsignoff)

----------------
Description
----------------
Writes acer_tm11_charts.json - the depth-velocity danger chart file that ND Dam Breach Runner and ND Dam Breach Screening (core/nd_hazard.py) read - from ND Dam Hazard's own curves (the REG_05.2026 table, sampled every 0.1 ft/s), so all three tools use the same chart. One engineer's sign-off is enough: the file is marked 'digitized' and signed off by the name in 'Signed off by' (a second engineer may be recorded in 'Checked by'; tick 'Require a second checker' to demand one). Without a name the polygons are written for review with status 'not digitized' and the other tools refuse the chart method. With 'Install in the plugins' the signed-off file replaces core/acer_tm11_charts.json of the installed Runner and Screening, so their chart method uses it at once. The plugins ship with the file signed off by Nicholas Bendickson (2026-10-12).

To check the curves against the printed figures, give a scan (PNG / JPEG) of TM 11 Figure 2 and / or 3 and a calibration: two or more reference points 'x_px, y_px = velocity_ft/s, depth_ft' separated by ';' (two points: the axes are taken parallel to the image edges; three: exact affine fit; four or more: least squares with a residual). The SVGs show the curves on the scan with a grid and a legend. Without a scan the curves are drawn on a plain chart.

Chart_SignOff.txt records the names as entered, what the curves are, their documented fit residuals and the check of nd_hazard's zones against ND Dam Hazard's zones. The tool cannot confirm that a check was made. Not yet run in a real QGIS.
