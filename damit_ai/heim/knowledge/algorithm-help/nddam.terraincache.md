```
2 - Cache terrain per dam (nddam:terraincache)

----------------
Description
----------------
Writes dam_<ID>.tif (float32 metres, EPSG:5070) for every dam. Source is either the USGS 3DEP service (needs internet, run once) or a local folder of ND LiDAR-derived DEM tiles (works offline). Existing files are reused, so the batch can be re-run or resumed. Local tiles tagged in feet are converted to metres; untagged tiles are taken as metres (a warning is logged); tiles in different CRSs are each warped to EPSG:5070. 3DEP serves the best available resolution per location; check the resulting cell size where it matters.

----------------
Arguments
----------------

DAMS: Standardized dams
	Argument type:	source
	Acceptable values:
		- Path to a vector layer
SRC: Terrain source
	Default value:	0
	Argument type:	enum
	Available values:
		- 0: USGS 3DEP service
		- 1: Local DEM folder
	Acceptable values:
		- Number of selected option, e.g. '1'
		- Comma separated list of options, e.g. '1,3'
LOCAL: Local DEM folder (if local source) (optional)
	Argument type:	file
	Acceptable values:
		- Path to a file
RADIUS_FT: Half-width of clip around each dam (ft)
	Default value:	5000
	Argument type:	number
	Acceptable values:
		- A numeric value
		- field:FIELD_NAME to use a data defined value taken from the FIELD_NAME field
		- expression:SOME EXPRESSION to use a data defined value calculated using a custom QGIS expression
CELL: Cell size (m; the DEM's own unit - 10 m = 32.8 ft)
	Default value:	10
	Argument type:	number
	Acceptable values:
		- A numeric value
		- field:FIELD_NAME to use a data defined value taken from the FIELD_NAME field
		- expression:SOME EXPRESSION to use a data defined value calculated using a custom QGIS expression
OUT: Output folder
	Argument type:	folderDestination
	Acceptable values:
		- Path for an existing or new folder

----------------
Outputs
----------------

OUT: <outputFolder>
	Output folder
```
