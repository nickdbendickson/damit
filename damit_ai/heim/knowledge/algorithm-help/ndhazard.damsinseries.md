```
Dams in series screen (folder of dams) (ndhazard:damsinseries)

----------------
Description
----------------
Screens the dam folders directly inside the chosen folder (each with its own dam-break rasters and outputs/QA/Last_Run_Snapshot.json): for every pair, is the downstream dam inside the upstream dam's breach flood, how deep and when does the water arrive there, and is the downstream dam's own class higher. Writes Dams_In_Series_Screen.csv / .html in the chosen folder and in each dam's QA folder. A SCREENING TABLE only - it reads each upstream dam's own breach flood at the downstream dam's point and does not compute a combined breach. The depth threshold and search distance are the engineer's own screening values. Dam locations come from dam_location.json / .csv in the dam folder, or from an NID layer given here (matched by NID id or name).

----------------
Arguments
----------------

PARENT: Folder containing the dam folders
	Argument type:	file
	Acceptable values:
		- Path to a file
DEPTH_FT: Cascade candidate when the depth at the downstream dam is above (ft)
	Default value:	3
	Argument type:	number
	Acceptable values:
		- A numeric value
		- field:FIELD_NAME to use a data defined value taken from the FIELD_NAME field
		- expression:SOME EXPRESSION to use a data defined value calculated using a custom QGIS expression
TOLERANCE_FT: Search the nearest wet cell within (ft) of the downstream dam's point
	Default value:	500
	Argument type:	number
	Acceptable values:
		- A numeric value
		- field:FIELD_NAME to use a data defined value taken from the FIELD_NAME field
		- expression:SOME EXPRESSION to use a data defined value calculated using a custom QGIS expression
NID: National Inventory of Dams layer (to locate dams without a location file) (optional)
	Argument type:	vector
	Acceptable values:
		- Path to a vector layer

----------------
Outputs
----------------

CSV: <outputFile>
	Dams_In_Series_Screen.csv
HTML: <outputFile>
	Dams_In_Series_Screen.html
SUMMARY: <outputString>
	What the screen found
```
