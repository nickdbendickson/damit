```
Verify a run manifest (inputs and results unchanged?) (ndbreach:verifymanifest)

----------------
Description
----------------
Every model run writes run_manifest.json in its _breach_model folder: the software versions, the LISFLOOD-FP executable and every input file with their SHA-256, the settings, and the SHA-256 of the result rasters. This tool checks a dam folder (or a manifest file) against that record and lists what changed since the run: an input file replaced, a raster edited, a different LISFLOOD-FP executable, or the manifest itself modified. Files larger than 2 GB are compared by size and three 8 MB pieces.

----------------
Arguments
----------------

TARGET: Dam folder or run_manifest.json
	Argument type:	file
	Acceptable values:
		- Path to a file

----------------
Outputs
----------------

RESULT: <outputString>
	Result
MANIFEST: <outputFile>
	Manifest
```
