```
Reproduce a past run from its package (ndhazard:reproduce)

----------------
Description
----------------
Re-runs the classification recorded in a submittal / reproduce package (folder or .zip; Run_Settings.json and the packaged inputs) in a NEW work folder and compares the result with the package's. Internet downloads are off; the flood rasters are taken from the package or from the rasters folder given here. Writes Reproduction_Check.csv / .txt in the work folder. Says IDENTICAL only when the compared values match; a difference may come from a changed plugin version or a missing input.

----------------
Arguments
----------------

PACKAGE: Package (folder or .zip)
	Argument type:	file
	Acceptable values:
		- Path to a file
WORK_FOLDER: Work folder (new or empty)
	Argument type:	folderDestination
	Acceptable values:
		- Path for an existing or new folder
RASTERS_FOLDER: Folder with the flood rasters (if they are not in the package) (optional)
	Argument type:	file
	Acceptable values:
		- Path to a file

----------------
Outputs
----------------

WORK_FOLDER: <outputFolder>
	Work folder (new or empty)
STATUS: <outputString>
	IDENTICAL / DIFFERENT / NOT COMPARED / FAILED
CHECK_CSV: <outputFile>
	Reproduction_Check.csv
CHECK_TXT: <outputFile>
	Reproduction_Check.txt
```
