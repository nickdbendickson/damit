11 - Compare with a reference model (nddam:comparereference)

----------------
Description
----------------
Compares the tool-7 flood of a dam (max depth, max velocity, arrival time) with the same flood from another model - a HEC-RAS 2D run, a DSS-WISE Lite result (convert its rasters to GeoTIFF / feet first: ND Dam Hazard's import does that), or the ND Dam Breach Runner - with the Runner's own benchmark metrics (the same functions): fit index F = A∩B / A∪B (= critical success index), hit rate, false-alarm ratio, wet-area bias; depth bias / RMSE / MAE / 90th percentile error and depth-class agreement (classes 1, 3, 6 ft) over the cells both models flood; velocity and arrival the same way.
WHICH DAM: the tool-7 results layer (its depth_tif … fields) or the tool-7 output folder (<dam>_<scenario>_depth.tif …). One dam ID, or empty = every dam that has a reference in the reference folder.
REFERENCE: three rasters for one dam, or a folder: <folder>/<dam ID>/ with rasters named by kind (Depth (Max).tif, Velocity…, Arrival…), or files whose name holds the dam ID and the kind (DWR-5289_depth.tif). Units: US (ft, ft/s, h) or metric. The reference is resampled onto the tool-7 grid (nearest neighbour), as the Runner does. Tool 7's rasters are METRES and are converted to feet here.
WET THRESHOLD: a cell counts as flooded from this depth (ft) in both models; 1.0 ft is a screening value you choose (the Runner's default too).
OUTPUT per dam: <out>/<dam ID>/Benchmark_Summary.csv, Benchmark_Report.html, 'Benchmark Depth Difference (ft).tif' (this plugin minus the reference, feet) and 'Benchmark Extent Agreement.tif' (1 = only this plugin floods the cell, 2 = only the reference, 3 = both); with several dams also <out>/Benchmark_All.csv.
A difference points at terrain, roughness, breach hydrograph or boundary choices to look at; it does not say which model is right. Not run in a real QGIS during development (test doubles only).
