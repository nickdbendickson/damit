Review a submittal package (checklist) (ndhazard:reviewpackage)

----------------
Description
----------------
For the reviewer. Reads a submittal package (its folder, or the .zip - unzipped into the work folder) and NEVER writes into it. In the work folder: Review_Files_Check.csv (every file against the package's MANIFEST.csv SHA-256: missing / changed / extra), Model_Chain_Check.csv (the rasters the classification read against the ND Dam Breach Runner's run manifest packaged with it), optionally the reproduction of the run (reproduction/Reproduction_Check.csv), and Review_Report.html + Review_Checklist.csv: each item with an automatic finding and EMPTY decision (Accept / Question / Not applicable) and comment columns. The items are this tool's own checks, not the State's review criteria or regulatory requirements. Re-read the filled checklist with 'Summarize a filled review checklist'.
