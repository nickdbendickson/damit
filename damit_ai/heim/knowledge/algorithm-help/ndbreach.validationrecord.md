Validation record from a benchmark comparison (ndbreach:validationrecord)

----------------
Description
----------------
Writes a Word Validation Record from the folder that 'Compare with an approved study (benchmark)' (or the HEC-RAS import with the benchmark option) wrote: the identification of the study and of this model run, the agreement metrics with their verdict, the depth-class confusion matrix, the list of difference and agreement rasters, an acceptance statement, and a blank sign-off table (Prepared by / Reviewed by / Date).

Fields you leave empty stay blank in the record to be filled in by hand. The acceptance statement is what the responsible engineer decides; it is left blank unless you type it here. The record shows the tool's metrics and verdict; it does not state that the model is approved.
