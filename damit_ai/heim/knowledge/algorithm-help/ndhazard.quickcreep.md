Quick creep screen: new structures layer against every dam's flood (ndhazard:quickcreep)

----------------
Description
----------------
For every dam folder directly inside the chosen folder: samples the NEW structures layer (e.g. a new FEMA USA Structures or NSI release; points or polygons) on the depth raster the dam's last classification used and compares the wet structures with the structures of that run (matched by location). Lists NEW structures in the flood area and structures that are gone, with a 're-run recommended' flag per dam, in Quick_Creep.csv / .html in the chosen folder. It does NOT re-classify anything and runs no model - it tells which dams to re-run. A screen: a point reads the cell it lies in, a polygon the largest value of the cells whose centre is inside it (the classification reads the outline plus a 5-ft ring).

----------------
