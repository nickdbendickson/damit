9 - Sensitivity of the class (borderline dams) (nddam:sensitivity)

----------------
Description
----------------
Re-runs tools 5, 7 and 8 for the dams you give it (tip: select the review queue or the dams near a class boundary and tick 'Selected features only') with each chosen variant: the breach equations (Froehlich 2008 / 1995, Von Thun & Gillette erodible / resistant, MacDonald & Langridge-Monopolis 1984, NRCS TR-60 peak with a triangular hydrograph) and Manning n x0.75 and x1.25. Reports the class of every variant, the lowest and highest class, and class_stable = yes if all agree. A class that flips between reasonable assumptions needs an engineer's look.
