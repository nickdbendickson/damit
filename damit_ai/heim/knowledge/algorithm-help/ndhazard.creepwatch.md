Hazard creep watch (folder of dams, fresh data) (ndhazard:creepwatch)

----------------
Description
----------------
Re-classifies every dam folder directly inside the chosen folder with its own flood rasters but FRESH data (NSI, ND GIS Hub address points, FEMA outlines, roads, …), compares each result with that dam's previous run and writes Hazard_Creep_Watch.csv and Hazard_Creep_Watch_<date>.html in the chosen folder - dams whose class changed, or with newly flooded structures, roads or lifelines, first. It is a list of dams to look at, not a classification. To run it on a schedule: qgis_process run ndhazard:creepwatch --PARENT=<folder> (Windows Task Scheduler, cron). WORKERS > 1 classifies that many dams at the same time, each in its own qgis_process child process (QGIS stays usable; needs qgis_process - set ND_QGIS_PROCESS to its full path if it is not found; falls back to one dam after another when it is missing). WORKERS = 1 (default) runs the dams one after another in this session; each dam's downloaded data stays in this session's memory until QGIS closes, so use WORKERS > 1 for a long run. Batch_Hazard_Classification.csv (the class of every dam) is written as well.
