```
Dam portfolio dashboard (folder of dams) (ndhazard:portfolio)

----------------
Description
----------------
Reads the outputs of the dam folders directly inside the chosen folder (their summary, run log and QA snapshot files - nothing is re-run) and writes Dam_Portfolio.html and .csv: class, lives in jeopardy, open review items and data vintage per dam. A dam whose files are missing is a row of '-'. v2.10: also each dam's dam.json, the ND Dam Breach Screening results (summary.csv / tool-8 GeoPackage found in or directly inside the folder, or the Screening folder given here) and the ND Dam Breach Runner files, and a Next action column (screen, model, classify, review, refresh, none); dams needing an action come first. The Screening and Runner classes are previews; this plugin's class is the classification.

----------------
Arguments
----------------

PARENT_FOLDER: Folder containing the dam folders
	Argument type:	file
	Acceptable values:
		- Path to a file
OUTPUT_HTML: Dashboard file (.html; empty = Dam_Portfolio.html in that folder) (optional)
	Default value:	
	Argument type:	string
	Acceptable values:
		- String value
		- field:FIELD_NAME to use a data defined value taken from the FIELD_NAME field
		- expression:SOME EXPRESSION to use a data defined value calculated using a custom QGIS expression
SCREENING: ND Dam Breach Screening report folder (empty: looked for in the folder of dams) (optional)
	Argument type:	file
	Acceptable values:
		- Path to a file

----------------
Outputs
----------------

HTML: <outputFile>
	Dam_Portfolio.html
CSV: <outputFile>
	Dam_Portfolio.csv
SUMMARY: <outputString>
	Dams in the dashboard
```
