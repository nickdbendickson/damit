```
Add model results to a dam (ndhazard:adddamresults)

----------------
Description
----------------
Puts a model's results in the dam's folder in the Dams folder, where the batch classification finds them. Name the dam (its ID such as DWR-2801, or its name): when the Dams folder has no folder for it, one is made with a dam.json. The results go to &lt;dam&gt;/Hazard_inputs/Breach_&lt;MODEL&gt; (No_Breach_&lt;MODEL&gt; for a no-breach baseline); a folder that already holds results is never written into - the next number is used. DSS-WISE Lite zips / folders and LISFLOOD-FP .max / .maxVc / .inittm grids are converted to feet, ft/s and hours; HEC-RAS exported rasters are copied (SI rasters converted to feet); a HEC-RAS plan file (.p##.hdf) is converted by the plan import. The source is only read. results_provenance.json records the source, its sha256, the model and the time. A CSV with columns dam, source (and optionally model, scenario, crs, terrain) adds many dams.

----------------
Arguments
----------------

DAM: Dam ID or name (a new dam folder is made when there is none) (optional)
	Argument type:	string
	Acceptable values:
		- String value
		- field:FIELD_NAME to use a data defined value taken from the FIELD_NAME field
		- expression:SOME EXPRESSION to use a data defined value calculated using a custom QGIS expression
SOURCE: Model results: zip, .p##.hdf, .max or raster file (optional)
	Argument type:	file
	Acceptable values:
		- Path to a file
SOURCE_FOLDER: or: folder of model results (optional)
	Argument type:	file
	Acceptable values:
		- Path to a file
MODEL: Model
	Default value:	0
	Argument type:	enum
	Available values:
		- 0: Auto-detect
		- 1: DSS-WISE Lite
		- 2: HEC-RAS
		- 3: LISFLOOD-FP
	Acceptable values:

SCENARIO: Scenario

CSV: or: CSV of many dams (columns dam, source; optional model, scenario, crs, terrain) (optional)
	Argument type:	file
```
