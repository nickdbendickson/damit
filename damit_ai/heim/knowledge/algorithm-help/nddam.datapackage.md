0 - Build offline data package (nddam:datapackage)

----------------
Description
----------------
Copies the statewide layers you downloaded once into a single GeoPackage in EPSG:5070, optionally clipped to North Dakota, with standard field names the other tools pick up automatically:
structures: habitable (1/0: 0 only when OCC_CLS / PRIM_OCC name an uninhabited building - barn, shed, garage …; ND 5.2.1.1 / 5.3; a habitable yes/no field of the layer wins), mobile (1/0, mobile / manufactured / trailer, or a mobile yes/no field), occ_cls, prim_occ; structure_points: the same structures as points (point on surface) for ND Dam Breach Runner's receptors
roads: aadt (missing, zero or NaN = empty), road_class, level (Low/Medium/High by ND 5.2.1.2 as tool 8 rates it; no AADT = Medium by assumption)
railroads: passenger (1/0, FRA PASSNGR codes or yes/1), trains_day, level
flowlines, waterbodies, dam_lines, lifelines and dams are copied as they are (geometry reprojected).
OR: A PACKAGE EXPORTED BY ND DAM HAZARD (its 'Export data package for ND Dam Breach Screening', v2.10 or later): every input left empty is taken from the package's layer of the same name (structures, roads, railroads, flowlines, lifelines, dams - and waterbodies / dam_lines if the package has them; ND Dam Hazard's pack has neither). Layers you give explicitly always win. The package's habitable / mobile flags (ND Dam Hazard's own reading) and aadt / passenger / trains_day are kept; level is rated again with this plugin's rule. What the package lacks is reported. This tool works without ND Dam Hazard.
Suggested sources: FEMA USA Structures (North Dakota), NDDOT traffic volumes (AADT), FRA North American Rail Network lines, USGS NHD High Resolution, the DWR dam lines. After this, the whole workflow runs offline except for the 3DEP terrain option.
