Mark the classification reviewed (ndhazard:markreviewed)

----------------
Description
----------------
For the reviewer. Records the review of this dam's hazard classification as a 'reviewed' status in <dam folder>/dam.json (the record shared with ND Dam Breach Runner and ND Dam Breach Screening): the reviewer, the decision (Accepted / Accepted with comments / Returned), the comments, the number of open items and the SHA-256 of the submittal package's MANIFEST.csv when the package (folder or .zip) is given, so the record says which package was reviewed. One line is appended to outputs/QA/Review_Log.csv. Nothing else in dam.json changes - no value of another tool is overwritten - and the package is never written to. The dashboard (ndhazard:portfolio) shows 'review' as the next action while open items remain. 'Returned' always counts at least one open item. The decision words are this plugin's record of the review, not a regulatory finding. Not run in a real QGIS (simulated QGIS only).
