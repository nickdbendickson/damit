```
Fill a form template from a dam's results (ndhazard:fillform)

----------------
Description
----------------
Fills the {{KEY}} placeholders of a template (.docx, .txt, .md, .html or .csv) with values read from the dam's outputs folder (Form_Values.csv lists every KEY). It never guesses: a placeholder that has no KEY, or no recorded value, is left as it is and reported. The plugin does not contain the State's form - use your own template.

----------------
Arguments
----------------

OUTPUT_FOLDER: The dam's outputs folder (or the dam folder)
	Argument type:	file
	Acceptable values:
		- Path to a file
TEMPLATE: Template (.docx, .txt, .md, .html, .csv)
	Argument type:	file
	Acceptable values:
		- Path to a file
OUT_FILE: Filled form (file; empty = next to the template, with _filled added) (optional)
	Default value:	
	Argument type:	string
	Acceptable values:
		- String value
		- field:FIELD_NAME to use a data defined value taken from the FIELD_NAME field
		- expression:SOME EXPRESSION to use a data defined value calculated using a custom QGIS expression

----------------
Outputs
----------------

FILLED: <outputFile>
	Filled form
SUMMARY: <outputString>
	Placeholders not filled
```
