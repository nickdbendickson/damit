Extract dams, dikes and culverts from OpenStreetMap (ndfind:osm)

----------------
Description
----------------
Dams, weirs, dikes, embankments, culverts and fords of an OpenStreetMap file (.osm.pbf /
    .osm, the Geofabrik extract) as a point layer 'osm_structures' (EPSG:5070; a line or an area
    at its centre) to give the other tools as known structures. Returns 'out|layername=...'.<br><br>Tags read: waterway=dam / weir, man_made=dyke / embankment, tunnel=culvert, ford=yes. Use the Geofabrik North Dakota extract the offline pack's OpenStreetMap step downloads (north-dakota-latest.osm.pbf). The pack's OSM_crossings layer (culverts, fords, rail bridges) can be given to the crossings tool as it is; this tool adds the dams, weirs and dikes. Give the output to the other tools as a known-structure layer.

----------------
Arguments
----------------

OSM: OpenStreetMap file (.osm.pbf or .osm)
	Argument type:	file
	Acceptable values:
		- Path to a file
EXTENT: Only this area (empty = all of it) (optional)
	Argument type:	extent
	Acceptable values:
		- A comma delimited string of x min, x max, y min, y max. E.g. '4,10,101,105'
		- Path to a layer. The extent of the layer is used.
OUT: Output GeoPackage
	Argument type:	fileDestination
	Acceptable values:
		- Path for new file

----------------
Outputs
----------------

OUT: <outputFile>
	Output GeoPackage
