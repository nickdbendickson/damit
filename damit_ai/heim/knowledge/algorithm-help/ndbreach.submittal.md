Submittal report (Word) (ndbreach:submittal)

----------------
Description
----------------
Writes a Word (.docx) submittal report from a dam folder: summary of results, dam and reservoir data, breach parameters and method with the run's warnings, flood scenario, hydraulic model settings and mass balance, results (depth, velocity and arrival tables, the EAP map, hydrograph and gauge figures), receptors and consequences, sensitivity and cascade results, the assumptions and what must be verified, the run manifest, a reviewer checklist pre-filled from what the folder contains, and a file list. Whatever the folder does not hold is left out. It reads the run report in _breach_model, the CSV and GeoJSON products, consequences*.csv/.md and run_manifest.json when present. Figures are SVG in the folder; they are embedded as PNG when QGIS's Qt SVG, cairosvg, rsvg-convert, inkscape or LibreOffice can convert them, and are listed by file name otherwise. Word builds the table of contents (page numbers) when the file is opened: answer Yes to update fields.
