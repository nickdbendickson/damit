```
Compare with the Breach Runner / Screening rules (nd_hazard) (ndhazard:rulecompare)

----------------
Description
----------------
Re-classifies the structures of a finished ND Dam Hazard run with the rules of ND Dam Breach Runner / ND Dam Breach Screening (their core/nd_hazard.py, found in the installed plugins or given here): the depth / velocity rasters sampled their way (cells inside the outline, maximum depth with maximum velocity), habitability and mobile home from the occupancy text, and either ND Dam Hazard's own TM 11 curves as charts (so only sampling, habitability and the rules differ), the conservative no-chart method, or a signed-off chart file.

Writes outputs/QA/Rules_Comparison.csv and .html: per structure both results, whether they differ and why (sampling area, habitability, mobile home type, chart / method, judgment zone rule), the dam class from each and a verdict. ND Dam Hazard remains the classification authority. Not yet run in a real QGIS.

----------------
Arguments
----------------

OUTPUT_FOLDER: The dam folder or its outputs folder
	Argument type:	file
	Acceptable values:
		- Path to a file
DEPTH: Breach maximum depth (ft) - empty: the one in QA/Run_Settings.json (optional)
	Argument type:	raster
	Acceptable values:
		- Path to a raster layer
VELOCITY: Breach maximum velocity (ft/s) - empty: from QA/Run_Settings.json (optional)
	Argument type:	raster
	Acceptable values:
		- Path to a raster layer
METHOD: nd_hazard lethality method
	Default value:	0
	Argument type:	enum
	Available values:
		- 0: nd_hazard charts made from ND Dam Hazard's curves (only sampling / habitability / rules differ)
		- 1: nd_hazard conservative method (no chart)
	Acceptable values:
		- Number of selected option, e.g. '1'
		- Comma separated list of options, e.g. '1,3'
CHART_FILE: Or: a signed-off chart file (.json) - overrides the method (optional)
	Argument type:	file
	Acceptable values:
		- Path to a file
ND_HAZARD_PY: nd_hazard.py (empty: from the installed Breach Runner / Screening) (optional)
	Argument type:	file
	Acceptable values:
		- Path to a file
WET_FT: nd_hazard 'any depth' (ft)
	Default value:	0.1
	Argument type:	number
	Acceptable values:
		- A numeric value
		- field:FIELD_NAME to use a data defined value taken from the FIELD_NAME field
		- expression:SOME EXPRESSION to use a data defined value calculated using a custom QGIS expression

----------------
Outputs
----------------

CSV: <outputFile>
	Rules_Comparison.csv
HTML: <outputFile>
	Rules_Comparison.html
VERDICT: <outputString>
	Verdict
```
