Flood animation (GIF / MP4 / time-enabled layers) (ndbreach:animation)

----------------
Description
----------------
Animates a breach run from the depth snapshots LISFLOOD-FP wrote (<dam folder>/_breach_model/depth_snapshots.npz): each frame is a hillshade of the DEM with the depth in the EAP map's classes, the time after breach initiation (T-hh:mm before it, in the flood scenario), a timeline, a legend and a scale bar, and a line around the area the flood has reached at the arrival depth so far. Writes PNG frames, an animated GIF and, when ffmpeg is on the PATH, an MP4. The frames show only the area the flood reaches; a grid larger than the size asked for is reduced by the deepest cell of each block.

Optionally writes one depth GeoTIFF (ft) per frame and 'Depth frames.json' with their time ranges, and loads them as time-enabled layers in a group, so QGIS's temporal controller plays the flood: breach initiation is the base date-time (default 2000-01-01 00:00, so the clock reads the hours after initiation). Loading the time-enabled layers was written against the QGIS 3.28 API but has not been tested in QGIS; if a range is not set, the GeoTIFFs and the JSON index are still there.

The hillshade uses the DEM you give, or the model's own DEM when the model files were kept. The snapshots come from LISFLOOD-FP even when the final rasters come from ANUGA.
