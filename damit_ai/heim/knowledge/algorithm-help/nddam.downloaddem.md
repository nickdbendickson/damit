Download DEM (dam, county, or state) (nddam:downloaddem)

----------------
Description
----------------
Writes one local DEM for a dam, a county, or the state. Resolution is 10 m or 1 m. USGS 3DEP: source USGS 3DEP ImageServer, native CRS EPSG:5070, native units metres, native file type GeoTIFF. ND DWR LiDAR: source ND QL2 on lidarftp.swc.nd.gov / lidar.dwr.nd.gov: DEM_Imagine is Erdas Imagine .img at 1 m in the tile's UTM CRS (EPSG:26914 or EPSG:3721, metres), elevations in metres; ASCII_Grids_ft are ASCII grids in ND State Plane feet (EPSG:2265 / 2266), elevations in feet, converted x 0.3048 (DEM_Imagine is used when both are there). Either source is saved as GeoTIFF float32, tiled, DEFLATE, CRS EPSG:5070, units metres (written as the band's unit, so the Runner's 'Detect from the raster' reads it), at the chosen cell size. USGS 3DEP is fetched in 1,200 px export requests: at 1 m these are 1.2 km chunks, so a 10 mi buffer is 27 x 27 = 729 requests - request chunks, not lidar tiles; for 1 m the native tile source below is usually the better choice. A _dem.txt file next to the raster lists those facts. 10 m is the working copy. 1 m is for one dam or a county you are about to inspect; a 1 m state is very large. An existing file of the same name is reused. USGS 3DEP 1 m lidar tiles (native, TNM): the lidar project tiles themselves (10 km GeoTIFFs at 1 m, UTM metres, about 275 MB each) from The National Map, not a resampled image. Area: the box, else the dam folder (the Runner's model bounds, else its dam point and the buffer), else the dam point and buffer, else the county. The first run only lists the tiles (project, collection and publication dates, sizes), the total download and the free disk space; tick 'Download the listed tiles' to download them. Tiles go to the tile folder, else <suite data folder>/dem/lidar_1m/ (never the offline pack or a read-only folder); tiles already there are skipped and a cut download resumes. Where two projects cover the same tile the newest collection is used and the log says so. The result is <DAM_ID>_1m_lidar.vrt in the output folder (band unit metres), with the coarser DEM underneath when one is given or <DAM_ID>_10m_5070.tif is there - converted to metres when it records feet, not used when it records no unit - and <DAM_ID>_1m_lidar.json listing the projects and tiles.
