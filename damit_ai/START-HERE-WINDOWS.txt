Heim and Vor on Windows: start here
===================================
Two assistants that run on this PC only (nothing is sent anywhere):
  Vor   answers from your library of dam-safety publications and quotes the page.
  Heim  answers about the dam-suite tools, their settings and known behaviours, and reads
        finished breach runs so you can ask for exact numbers.

1. Install (about 15-60 minutes, most of it downloading 8-22 GB of models)
   Double-click  Install-Windows.cmd  in this folder.
   - If Windows says "Windows protected your PC": click More info, then Run anyway.
   - It needs no admin rights. If it asks whether to let PowerShell load your profile, type y.
   - If it stops, read the last lines, fix that (often: free disk space), and double-click it
     again. It carries on where it stopped. Everything it printed is in
     %USERPROFILE%\local-ai\install.log

2. Open Local AI: it is in your Start menu and on your desktop.
     Ask questions, add documents (drop PDFs on the Library tab), get more from the download
     catalog, fix what Health reports with one press, test the answers and install updates.
     Nothing to type, and nothing needs admin rights.
   Or open a NEW PowerShell or Command Prompt window (Start menu, type PowerShell) and type:

3. Try these:
     vor "what breach width does Froehlich 2008 give?"
     heim "what does REFINE_NEAR do?"
     ai            both on one page in your web browser
     heim help     the short list of commands

4. If something is not right:
     ai-doctor     checks everything and ends with one OK / WATCH / PROBLEM line for each
                   assistant; each PROBLEM line says what to run.

Vor's library starts empty unless this folder came with an offline pack. Add PDFs with
  vor add FILE ...        (drag the files into the window to type their paths)

Both are assistants, not engineers: check every answer against the cited page or the code
before relying on it in a dam-safety decision.

More: INSTALL-cross-platform.md (all options, offline installs, the sandbox mode).
