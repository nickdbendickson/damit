about=One window (Plugins > DamIT > Start here...). Scans the suite data folder for dams, terrain, structures / footprints, roads and railroads (any jurisdiction; no North Dakota pack is required, and DamIT Data's download folders are recognized), lists the DamIT plugins and their versions, proposes the DamIT Catalog preset for the chosen state (or leave it for an agency preset or custom mode), saves the choices in the DamIT suite settings without overwriting values already set, and writes damit_screen_settings.json in the work folder. Continue opens DamIT Screener's preflight with the work folder, dams, terrain, receptors, preset and the settings file filled in. Hand-off targets are damit_screen:preflight / :runchain and damit_run:rundam only; nddam / ndbreach ids are refused.
