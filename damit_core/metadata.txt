about=DamIT Core holds the code DamIT Setup, DamIT Data, DamIT Hazard Lite and DamIT PMP share (damit_core.lib): the suite settings store (QgsSettings group damit/, or a JSON file named by the DAMIT_SETTINGS environment variable), the list of DamIT plugins with their Processing provider ids and a version / dependency check, a table of US states and territories (FIPS, bounding box, Geofabrik and Microsoft footprint names), dam-record normalization onto the DamIT Screener dam fields, DamIT Catalog access (preset list, preset for a state) and an HTTP helper (QGIS network settings inside QGIS, urllib outside). It holds no jurisdiction thresholds: those live in DamIT Catalog. It depends on no DamSafety plugin. DamIT Hazard, Screener, Runner and Crest do not use it yet in 0.1.0; they can switch later.

changelog=0.3.2 - (2026-11-20) shared_defaults.from_runner_method records an Xu & Zhang (2009) Runner run (xu_zhang2009_piping / _overtopping) as its failure mode and the "xu_zhang2009" equation, so dam.json no longer stores null for it (from DamSafety Core, DWR_Plugins 07ab314c M3b; with DamIT Runner 0.7.11). "xu_zhang2009" is recorded but is not a shared-defaults breach_method choice. Records only.
    0.3.1 - (2026-11-18) lib/http.py download_file no longer leaks on a failed request: the temporary file is opened before the request and closed before cleanup, and the HTTPError's own socket is closed (a Windows cleanup could fail with PermissionError on the open file). Tests: damit_core/tests/test_core.py (a local server that answers 404).
    0.3.0 - (2026-11-13) shared defaults file: data/defaults.json holds the suite's starting values (sunny_day_start_pool max_pool, pmf_breach_volume storage_at_start_pool, failure_mode piping, breach_method froehlich2008, manning_n 0.06), in the same 'dam-defaults' format as DamSafety Core 1.2.0 and Crest. Your changes go to ~/DamIT/defaults.json (or the setting defaults_file / env DAMIT_DEFAULTS), holding only the keys you changed. lib/shared_defaults.py reads, checks, merges (never raises) and saves them and builds the 'assumptions' entry a run writes into dam.json. Tests: tests/test_shared_defaults.py.
    0.1.0 - first release: settings store, plugin registry and suite check, state table, dam-record helpers, catalog access, HTTP helper, About entry.
