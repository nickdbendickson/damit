about=DamIT Core holds the code DamIT Setup, DamIT Data, DamIT Hazard Lite and DamIT PMP share (damit_core.lib): the suite settings store (QgsSettings group damit/, or a JSON file named by the DAMIT_SETTINGS environment variable), the list of DamIT plugins with their Processing provider ids and a version / dependency check, a table of US states and territories (FIPS, bounding box, Geofabrik and Microsoft footprint names), dam-record normalization onto the DamIT Screener dam fields, DamIT Catalog access (preset list, preset for a state) and an HTTP helper (QGIS network settings inside QGIS, urllib outside). It holds no jurisdiction thresholds: those live in DamIT Catalog. It depends on no DamSafety plugin. DamIT Hazard, Screener, Runner and Crest do not use it yet in 0.1.0; they can switch later.
