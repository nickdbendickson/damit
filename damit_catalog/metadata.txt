about=Single source of truth for the DamIT plugins (DamIT Screener, DamIT Runner, DamIT Hazard). Every threshold, label map, method parameter, scenario and modifier lives in data/*.json, so presets can be updated without a plugin code release; set the DAMIT_CATALOG_DIR environment variable to use an edited copy. Preset mode loads a state or agency bundle; custom mode shows method IDs and parameters without branding. Output of the DamIT plugins is a suggested classification only; the engineer of record and the regulating agency make the determination.
